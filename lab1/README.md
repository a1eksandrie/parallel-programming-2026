# Лабораторная работа 1. OpenMP

## Задачи
- **task1** — вывод идентификатора потока и "Hello World"
- **task2** — вычисление скользящего среднего с разными schedule
- **task3** — вывод идентификаторов потоков в обратном порядке (несколько способов)

## Требования
- Visual Studio 2019/2022 или g++ с поддержкой OpenMP
- Число потоков и размер задачи передаются через командную строку

## Сборка и запуск (Visual Studio)

1. Создайте консольный проект C++.
2. В свойствах проекта: **C/C++ → Язык → Поддержка OpenMP = Да**.
3. Вставьте код нужной задачи.
4. В **Отладка → Аргументы команды** укажите параметры.

### Примеры аргументов

| Задача     | Аргументы команды |
|------------|-------------------|
| Задача 1   | `8`               |
| Задача 2   | `8 16000`         |
| Задача 3   | `8`               |

## Сборка и запуск (командная строка, g++)

```bash
# Задача 1
g++ -fopenmp task1.cpp -o task1
./task1 8

# Задача 2
g++ -fopenmp task2.cpp -o task2
./task2 8 16000

# Задача 3 (пример)
g++ -fopenmp task3_single.cpp -o task3
./task3 8
```
