# Лабораторная работа №4

## Задача
- **sum_formula** — вычисление значения по формуле  
  \((\sum x + \sum y + \sum z) / 3N\)  
  с использованием функциональной декомпозиции и критических секций

## Требования
- Visual Studio 2019/2022 или g++ с поддержкой OpenMP
- Имя файла с точками и число потоков передаются через командную строку

## Формат входного файла
Каждая строка содержит три числа — координаты точки:
```
x y z
```

## Сборка и запуск (Visual Studio)

1. Создайте консольный проект C++.
2. В свойствах проекта: **C/C++ → Язык → Поддержка OpenMP = Да**.
3. Вставьте код программы.
4. В **Отладка → Аргументы команды** укажите параметры.

### Примеры аргументов

| Действие                        | Аргументы команды      |
|--------------------------------|------------------------|
| Генерация файла (1 млн точек)  | `generate 1000000`     |
| Генерация файла (10 млн точек) | `generate 10000000`    |
| Запуск (1 поток)               | `points.txt 1`         |
| Запуск (2 потока)              | `points.txt 2`         |
| Запуск (3 потока)              | `points.txt 3`         |
| Запуск (8 потоков)             | `points.txt 8`         |

## Сборка и запуск (командная строка, g++)

```bash
g++ -fopenmp sum_formula.cpp -o sum_formula

# Генерация файла с точками
./sum_formula generate 1000000
./sum_formula generate 10000000

# Запуски
./sum_formula points.txt 1
./sum_formula points.txt 2
./sum_formula points.txt 3
./sum_formula points.txt 8
```
