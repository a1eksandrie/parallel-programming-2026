# Лабораторная работа №2

## Задача
- **matrix_mult** — умножение квадратных матриц (последовательная и параллельная версии)

## Требования
- Visual Studio 2019/2022 или g++ с поддержкой OpenMP
- Размер матрицы (`N`) и число потоков передаются через командную строку

## Сборка и запуск (Visual Studio)

1. Создайте консольный проект C++.
2. В свойствах проекта: **C/C++ → Язык → Поддержка OpenMP = Да**.
3. Вставьте код программы.
4. В **Отладка → Аргументы команды** укажите параметры.

### Примеры аргументов

| Запуск              | Аргументы команды |
|---------------------|-------------------|
| Маленькая матрица   | `8 1`             |
| Маленькая матрица   | `8 4`             |
| Большая матрица     | `500 1`           |
| Большая матрица     | `500 2`           |
| Большая матрица     | `500 4`           |
| Большая матрица     | `500 8`           |

> Первый параметр — размер матрицы `N`, второй — число потоков.

## Сборка и запуск (командная строка, g++)

```bash
g++ -fopenmp matrix_mult.cpp -o matrix_mult

# Примеры
./matrix_mult 8 1
./matrix_mult 8 4
./matrix_mult 500 1
./matrix_mult 500 2
./matrix_mult 500 4
./matrix_mult 500 8
```
