## Требования к выполнению

1. Работа выполняется **индивидуально**. Язык — **C++** (выбран один раз на весь семестр).
2. Запрещается использовать библиотечные функции, реализующие целиком решаемую задачу (готовое умножение матриц и т. п.).
3. Число потоков и размер задачи передаются программе **через командную строку**.
4. Код размещается в публичном репозитории на GitHub: папки `lab1`…`lab4`, в каждой — код и файл README.
5. По ходу выполнения делаются **скриншоты** вывода программы (каждый запуск, о котором говорится в задаче). На скриншоте должна быть видна команда запуска и весь вывод.
